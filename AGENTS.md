# anarrativelens.com — NL Main Brand Site

> Astro site for A Narrative Lens — primary brand presence, services, case studies.

## Tech Stack

- Astro 6.x, TypeScript
- Netlify (deploy)
- Tailwind CSS

## Commands

```bash
npm run dev          # local dev
npm run build        # production build
npm run preview      # preview build
```

## Content

Repository-local content. Site pages, products, posts, config, and media live under `src/content/` and `public/`; do not point loaders or media paths at the Vault website mirror.
